# Simple Interest Calculator

## Description

This project is a simple interest calculator that calculates simple interest based on the principal amount, interest rate, and time.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

- Principal = Initial amount of money
- Rate = Annual interest rate
- Time = Time in years

## Example

If the principal is $1,000, the interest rate is 5%, and the time is 2 years:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = $100
